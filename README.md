# Dynamic landscape genetics analyses for southern Sierra Nevada fisher
This repository includes data and code for the following article: 

**"Dynamic landscape genetics predicts disturbance-driven declines in genetic connectivity in an endangered forest carnivore"** 

by Eric Palm, Erin Landguth, Katherine Zeller, Rebecca Green, Kristine Pilgrim, Sarah Stock, Craig Thompson, Michael Schwartz, and Jody Tucker

# Notes 
- Genetic sample locations have been geomasked so they do not represent actual locations.
- Please open the `fisher_lga.Rproj` file to start RStudio before opening individual scripts to ensure that relative file paths in the code work correctly.
- This repository will be updated to include additional files scripts.

# Data and code DOI: 

Data and code will be permanently archived with a DOI at zenodo.org upon article acceptance in a peer-reviewed scientific journal.
